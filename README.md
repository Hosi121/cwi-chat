# CwI Chat — Caption-with-Intention 風 WoZ チャット

ChatGPT 風の UI で、AI の返答を **文字の太さ・色・動き・間** で「言い方」ごと伝える試作です。
音声がないテキストチャットで、人間側が「ろうあ者のように」失っているパラ言語情報を、
Caption with Intention（CwI）のダイナミック・タイポグラフィになぞらえて補います。
推論は行わず、Wizard-of-Oz（WoZ）方式で `scenarios.js` の台本を再生します。

## 使い方

```bash
cd ~/cwi-chat
python3 -m http.server 8000     # http://localhost:8000/ を開く（index.html を直接開いても動きます）
```

- 左のシナリオを選ぶと台本が始まります。何を入力しても、台本の次の返答が返ります（自動応答）。
- 入力欄の上の「台本の想定発話」チップを押すと、想定された発話が入力されます。
- 返答中のメッセージをクリックするとスキップ、「↺ 再生」でもう一度再生できます。
- 「表現（CwI）」を OFF にすると、同じ本文が通常のストリーミング風（均一速度・装飾なし）で出ます。対照条件用です。
- `Ctrl+.` で Wizard パネル。台本の任意の行を送る／自由作文して送る／テンポ調整／ソース表示ができます。
- 「別ウィンドウで Wizard を開く」で `?wizard=1` の操作専用ウィンドウが開きます（同じブラウザ内で BroadcastChannel 経由）。参加者画面と Wizard 画面を分けた WoZ 実験に使えます。

## Live モード（OpenAI に装飾ルールを渡して生成する）

台本の代わりに、system prompt に装飾ルールを渡した OpenAI モデルが返答をマークアップ付きで生成します。

```bash
cd ~/cwi-chat
# .env に OPENAI_API_KEY=sk-... を書く（キーだけ 1 行でも可）
node local/server.mjs              # http://localhost:8787/ を開く
```

- サーバーが `.env` のキーで OpenAI に中継するので、ブラウザにキーは渡りません。
- 画面左下の「Live（OpenAI）で応答」を ON にするか、上部の「WoZ 台本」バッジをクリックすると Live モードになります。
- モデルは `.env` の `OPENAI_MODEL`（既定 `gpt-5.6-luna`）か、Wizard パネルの「モデル」欄で変えられます。
- システムプロンプト（装飾ルール）は `prompt.js` にあり、Wizard パネルから編集して試せます（編集内容はブラウザに保存）。
- 返答は SSE でストリーミングされ、受け取りながら「間」つきで再生されます。冒頭の `{pre:…}` で「考え中」表示の種類が変わり、待ち時間は実際の応答遅延です。
- `node local/server.mjs` を使わず file:// で開いた場合は、Wizard パネルにキーを入れるとブラウザから直接 api.openai.com に接続します。

## マークアップ

| タグ | 意味 | 見え方 |
|---|---|---|
| `{sure}…{/}` | 断言・確信 | やや太く、まっすぐ現れる |
| `{maybe}…{/}` | 推測・自信なし | 細く薄く、点線下線、ぼやけて現れ、間隔がゆらぐ |
| `{warm}…{/}` | 共感・寄り添い | ローズ色、下からふわっと |
| `{glad}…{/}` | 喜び | オレンジ、跳ねる |
| `{care}…{/}` | 注意・警告 | 赤、太く、小さく震える |
| `{sorry}…{/}` | 謝罪 | 青灰、少し小さく、沈むように |
| `{joke}…{/}` | 冗談・軽さ | 紫、字間広め、少し揺れる |
| `{think}…{/}` | 考え中・独り言 | 灰色、小さく、ゆっくり |
| `{em}…{/}` | 強調 | 極太、下マーカー、ポップ |
| `{big}…{/}` `{small}…{/}` | 声の大きさ | 文字サイズ |
| `{slow}…{/}` `{fast}…{/}` | テンポ | 表示間隔 |
| `{rise}…{/}` `{fall}…{/}` | 語尾の上げ下げ | 文字が徐々に上（下）へ |
| `{strike}…{/}` | 言い直し | 表示後に取り消し線 |
| `{pause:600}` | 間（ms） | 表示が止まる |
| `{br}` | 改行 | |
| `{cue:少し考えて}` | ト書き | 小さな灰色の（…） |
| `{dot}…{/}` | 傍点 | 文字の上に圏点。控えめな強調 |
| `{formal}…{/}` | 明朝・改まって | 明朝体に切り替わる |
| `{tremble}…{/}` | 震え | 表示後も小さく震え続ける |
| `{fade}…{/}` | 尻すぼみ | 文末に向けて細く薄くなる |
| `{drawl}…{/}` | 溜め | 字間が開く |
| `{retype:誤|正}` | 打ち直し | 誤を打ち、消して、正を打つ |
| `{honne:建前|本音}` | ルビの本音 | 建前の上に、少し遅れて小さく本音が出る |
| `{ref:相手の言葉}` | 照応 | 相手の吹き出しのその語が光り、アバターがそちらを見る |
| `{scene:serious}` | 照明 | 部屋を暗くして、いまの一言だけを照らす。`warm` `bright` もある |
| `{pre:think}` | 返答前の様子 | 冒頭に置く。`quick` `think` `deep` `hesitate` |

タグは入れ子にできます（例 `{warm}ここが{em}大事{/}です{/}`）。`{/}` は直近のタグを閉じます。
返答前の「考え中」表示は `pre: 'quick|think|deep|hesitate <ms>'` で指定します。

句読点の後には自動で間が入ります（、= 約 0.2 秒、。！？= 約 0.5 秒）。基本テンポは Wizard パネルのスライダーで変えられます。

## アバター・ターン交替・双方向

- アバターは丸いキャラクターで、ふだんは会話（右側のあなたの吹き出し）のほうを向いた斜め向きです。立場に合わせて口・頬・眉・頭のアホ毛が変わり、視線が動きます。あなたが入力していると入力欄を見て、考えているときはそっぽを向き、`{ref}` のときはあなたの吹き出しを読み、問いかけるときだけこちらを振り向きます。話し終わった顔は、まぶたを少し下ろして静かに聞いています。
- 照明 `{scene}` は、いま話している行を中心にした光の溜まりです。`serious` は周囲が青黒く沈み、過去のログがぼけて退き、照らされた文字と顔だけがほのかに光ります。`warm` は琥珀色のランプ、`bright` は文字から白い光が広がります。光は最後に出た文字を追いかけ、戻るときは光の輪が広がって部屋が明るくなります。
- 返答が問いかけで終わると、入力欄が一度光り、プレースホルダが「どうぞ」になります。あなたの番、の合図です。
- あなたの入力の様子（かかった時間、消した回数、長い間）を吹き出しの下に小さく表示し、Live モードではモデルにも渡します。迷いながら書くと、返答が急かさなくなります。Wizard パネルで両方 OFF にできます。
- 「表現の強さ」スライダーで、動き・色・間の振幅を 0〜100% で一括調整できます。実験の条件操作に使えます。

## Vercel にデプロイ

`api/` に Edge Function 版の中継（`chat.js`, `health.js`）が入っているので、そのまま Vercel に載せられます。静的ファイルはリポジトリ直下から配信されます。

```bash
npx vercel login          # 初回だけ
npx vercel link           # プロジェクトを作る / 紐づける
npx vercel env add OPENAI_API_KEY production
npx vercel env add APP_PASSWORD production   # 任意だが推奨
npx vercel --prod
```

環境変数:

| 名前 | 必須 | 説明 |
|---|---|---|
| `OPENAI_API_KEY` | 必須 | OpenAI の API キー |
| `OPENAI_MODEL` | 任意 | 既定モデル（`gpt-5.6-luna`） |
| `APP_PASSWORD` | 任意 | 設定すると Live 利用時にパスワードを求めます。URL を知っている人が誰でもあなたのキーで生成できてしまうのを防ぐためのものです |

ローカルの `local/server.mjs` も同じ環境変数（`.env`）を読みます。

## 1 ファイルにまとめる

```bash
./build.sh              # dist/cwi-chat.html（配布用・単体で開ける）
./build.sh --artifact   # Artifact 公開用（html/head/body タグなし）
```

## 構成

- `index.html` — 画面（サイドバー / スレッド / 入力欄 / Wizard パネル / 凡例）
- `style.css` — 見た目と、タグごとのアニメーション（`.run.t-*`）
- `cwi-chat.js` — マークアップ解析 → 禁則処理 → タイミング表 → 1 文字ずつ再生、WoZ 制御、BroadcastChannel
- `scenarios.js` — 台本（ここを書き換えて実験シナリオを作る）
- `prompt.js` — Live モードのシステムプロンプト（装飾ルール）
- `local/server.mjs` — 静的配信 + OpenAI 中継（`.env` のキーを使う）
